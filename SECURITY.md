# Security Policy

## Scope

MeshGate is an early engineering project. Do not use the current repository as evidence of production security readiness.

## Reporting

Please report suspected vulnerabilities privately to the repository maintainer rather than opening a public issue containing exploit details.

## Security design areas under active development

- authentication and authorization boundaries
- trusted and untrusted proxy headers
- request and response size limits
- upstream allow-listing
- resource exhaustion and abuse controls
- dependency and container scanning
- audit logging

Security claims will be tied to implemented controls and tests rather than labels.
